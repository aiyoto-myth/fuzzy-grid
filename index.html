Questions translators ask

Which CAT tools does it read?

Tables copied from analysis reports: tested with Trados Studio (English and German labels, the full report with a summary and one table per file), memoQ, Phrase (including the All/TM/MT/NT column groups), XTM labels, and band tables pasted into a PO email (it reads the agency's "Pay %" column, the rate and the PO total). Trados Studio's .xml analysis report opens directly. Wide CSV exports (one row per file, bands as columns) are not read yet: copy the table from the HTML report instead. Every band is listed with the number it read; lines it can't match are listed as skipped, and you can fix any row.

How does it know which column is the word count?

From the header row if there is one ("Words", "Characters"). Otherwise it looks for the columns whose bands add up to the Total row. If it can't tell, it says so and lets you pick the column.

What is "the base rate that pays what yours does"?

The base rate at which the agency's grid pays the same total as your own grid on this job. If your grid pays $1,000 and theirs counts 6,650 weighted words, that is $0.150 a word. It depends on how many matches this job has, so it moves from job to job; the job log averages it over every job you save for that agency.

What about internal fuzzy matches?

Trados lists them separately ("Internal fuzzy"). Each grid has a switch: price them like TM fuzzies, or as new words. Many translators argue for new words; many agencies use the fuzzy rate.

Are the example grids a standard?

No. They are examples to start from. Type the agency's exact percentages from their grid and your own from your rate card.
