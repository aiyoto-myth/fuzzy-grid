# Fuzzy Grid

Free tool for freelance translators: paste a CAT-tool match analysis (Trados, memoQ, Phrase) and see what an agency's fuzzy-match grid really pays you, and whether the PO adds up: https://samsbench.com/fuzzy-grid/

Single static page. Source and tests live in the app-bizz project (`apps/fuzzy-grid/`); this repo is the published copy.
